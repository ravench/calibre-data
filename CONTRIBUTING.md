# Contributing

Pull requests are welcome. [Adding or changing a calibre](docs/format.md#adding-or-changing-a-calibre)
in docs/format.md says how. An accepted pull request is carried into the
dataset by the maintainer and arrives with the next data update; the pull request itself is then
closed, not merged.

2. **Licence changes stay open.** Simon Giotta, who maintains this repository, may offer the whole

   closed or noncommercial licence.
3. **Facts with sources, nothing copied.** What you add are facts you measured or took from a source
   you cite. No text, tables, drawings or photos copied from books, C.I.P. or SAAMI sheets or web
   pages. You have the right to send it, and your employer, if you have one, agrees or has no rights
   in it.

A value you measured on a round yourself has the source `measured:<your GitHub username> <date>`,
for example `measured:ravench 2026-11-08`; say in a comment which round and which values.

Tick the box in the pull request description, or write in the pull request:

> I agree to the contributor terms in CONTRIBUTING.md.
